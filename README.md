## tju自用

略有门槛的超星形势与政策自动刷视频程序

因为我前面有几次忘刷了，想着写一个程序自动都刷了

### 运行环境：

1、jdk1.8+

2、可以运行maven项目的ide

3.1、X64，edge浏览器，且版本为135.0.3179.98正式版

3.2、如果浏览器版本不对就更新edge到这个版本，或者自行下载对应版本的EdgeWebDriver，替换src/main/resources/msedgedriver.exe

3.3、如果架构不对（比如mac），自行下载对应的WebDriver

3.4、chrome浏览器自行下载ChromeWebDriver，并修改代码及路径

### 使用方法

1、用ide加载项目，打开主函数，结合注释完成信息配置

2、使用/下载正确的WebDriver并正确设置路径

3、在对应的位置输入超星账号密码

4、手动进入要刷的课，进入如下界面

![f03fc9bba02617b2d775468af0b64f5](https://github.com/user-attachments/assets/ea01b78f-6c10-46a9-8559-dab06e387573)

复制上方网址并填入对应位置

5、运行，不要点击新产生的界面，否则会出现正在播放的视频意外暂停的情况，此时可以什么都不做，等相应时间过去，会自动播放下一个视频，也可以重启程序

### 运行效果

自动进入每个小课并按顺序播放视频，播放完成退出并进入下一个小课。自动跳过已完成的视频。播放约850分钟后停止（可以在代码里修改时长）

把电脑静音就可以睡觉去了
